# 前端交互实验室 · 迭代需求基线

状态：G0 冻结。仅修改 `kuntechnology/frontend-interaction-lab` 的 `/workspace/home-rebuild/overnight-lab` 隔离副本。文档与令牌由 freeze.sha256 签封；变更须说明原因并重新冻结。

## 目标

让实验室更稳定、安全，更容易通过键盘和触屏找到、体验、复用交互。主路径为：找到演示 → 实际体验 → 复制提示词或代码 → 继续探索。以清晰的现代界面支持工作，不用视觉装饰掩盖操作。

## 审计与基线修正

最初副本为 eaaf3ee，101 个源文件已逐字节核实。副本无 Git 元数据，已仅在本目录补建 Git 并读取远端；未修改邻近仓库。远端 main 已前进 15 个提交至 ed9a355，包含 src/lab.html 唯一编辑源、构建到 dist、54 个演示、Baseline 徽标、分类与 URL 筛选、复制代码、命令面板、原生 dialog/Popover、虚拟滚动、对比滑块、文件预览、Scroll Snap、@property 和八种主题上下文对比度检查。必须完整继承，不能用旧快照覆盖。

原始运行时 97 分片/no-store/document.write 风险已被远端静态构建解决。本次保留并验证此方案，不另造构建系统。当前 src 仍有 RxJS 查询进入 innerHTML 的 XSS 风险；旧拖拽排序、锚点、手势等仍需等价操作，复制失败和依赖容错需要加强。

## 保留与增量

保留远端全部 54 个演示的标题、描述、提示词、代码复制、目录和核心功能。保留框架矩阵、明暗主题、四种强调色、URL 筛选与主页链接。只为修复安全、稳定性、可访问性或明确的内容错误定点改实现。

本次外壳采用炭黑/暖白、信号橙、轻边框、系统字体和清晰的编辑式层级；桌面侧栏与移动分类入口保留内容密度，移除默认过量氛围光。首屏只使用真实计数和有效锚点。无新增生产外部依赖。

稳定性工作包括：静态直出和构建完整性回归；输入以文本节点渲染；复制错误如实提示；库初始化独立容错和显式重试；减少动态效果；排序上/下移、锚点方向键、手势按钮等触屏/键盘路径；Tab 和 Accordion 语义校验。统计保持非阻塞且只显示真实返回值。

只增加两个互补的原生 demo，避免重复远端已有能力：**55 可撤销列表操作**，实际移除和精确撤销、无自动消失时限、live region 状态；**56 可调整分栏**，分隔比例由原生 range 与左右按钮共同驱动，支持方向键/Home/End、触屏和重置。每个提供用途说明和复制提示词/代码。总数 54 → 56。

## 非目标

不改独立主页、安全控制台、Vercel、Supabase；不引入新框架、后端、账号、生成式服务、支付或自动化；不大规模重写原 demo。不把模拟数据说成真实服务，不把内部计划或未实现能力写进 UI。
