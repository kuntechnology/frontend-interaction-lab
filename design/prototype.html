17 个演示 现代 Web

库与框架演示需要联网加载 CDN；原生示例无需额外库。浏览器支持情况见各演示标注。

01 / 涟漪按钮

点击按钮，波纹从指针落点向外扩散并淡出，原生实现。

02 / 磁性按钮

光标靠近时按钮被轻轻吸引，离开后弹性回位。仅桌面端生效。

03 / 光标聚光灯

光标经过时照亮局部区域，其余内容压暗。触屏设备自动隐藏。

04 / 打字机

多段文案逐字打出、停顿、删除再循环，带闪烁光标。

05 / 数字滚动

数字从 0 平滑递增到目标值，rAF + 缓动函数实现。

06 / 滚动揭示

元素进入视口时淡入上移呈现，IntersectionObserver 触发一次。

07 / 视差滚动

背景层以 0.45 倍速移动，前景自然滚动，形成层次感。

08 / 3D 翻转

perspective + rotateY 实现正反面翻转，hover 与点击均可触发。

09 / 拖拽排序

HTML5 原生拖放实现列表重排，拖起项半透明占位。

10 / 折叠面板

同一时间仅展开一项，grid-template-rows 平滑过渡。

11 / Tab 切换

标签切换内容面板，下滑指示线平滑滑动到当前项。

12 / Toast 通知

右上角堆叠弹出，支持三种类型，自动消失可手动关闭。

13 / 骨架屏

加载前灰块占位并带流动高光，数据就绪后淡出换内容。

14 / 暗色模式

CSS 变量 + 状态类切换主题，偏好写入 localStorage 自动恢复。

15 / Canvas 粒子

粒子匀速运动，距离过近自动连线，鼠标经过产生斥力。

16 / 手绘画板

Pointer Events 绘制平滑曲线，支持笔宽、颜色与清空。

17 / GSAP 滚动编排

GSAP + ScrollTrigger：进入视口自动播放，点击按钮随时重放时间线。

18 / Lottie 矢量动画

播放内联 bodymovin 动画 JSON，SVG 渲染矢量缩放不失真，可暂停。

19 / Anime.js 补间

一条时间线串联位移、旋转、缩放与颜色循环补间，一键触发。

20 / Motion 交错

Motion（motion.dev）的 stagger 让列表项依次弹出，进入视口自动播放。

21 / Three.js 3D

WebGL 场景：环面结自转 + 点光源，鼠标移动改变视角姿态。

22 / p5.js 生成艺术

移动光标，彩色粒子沿路径流动，半透明覆盖形成笔触拖尾。

23 / ECharts 动态图表

折线图每 2s 追加数据点，模拟实时监控面板，可暂停与重置。

24 / D3 力导向图

力导向布局 + 节点拖拽：拖动任意节点，整图按物理规则重新分布。

25 / Swiper 3D 轮播

coverflow 3D 效果轮播：自动播放 + 分页器与前后箭头。

26 / Embla 轻量轮播

drag free 滑动 + 上/下一张控制，核心 API 仅约 12KB，无依赖。

27 / Hammer 手势识别

在面板上做手势：点击、长按、滑动、拖拽，实时显示识别结果。

28 / Tone 音序器

8 步音序器：点击格子编辑节拍，播放时高亮走位并发声。

29 / 多主题切换

同一套组件四个主题一键切换：颜色全部走 CSS 变量，原生实现。

30 / Vue 3.5 响应式

createApp 全局构建：ref 计数器、v-model 双向输入、computed 实时字数；子组件演示 3.5 响应式 props 解构。

31 / Preact + htm

htm.bind(preact.h) 免 JSX 编译，函数组件 + useState/useEffect 计数器，组件化拆分。

32 / htmx 超媒体

hx-get 触发局部内容 swap；every 3s 轮询。file:// 下用内联 template 模拟响应，双击即可运行。

33 / Alpine.js 属性驱动

纯 x-data / x-show / x-on / x-bind 实现下拉、模态、数量器，零手写业务 JS。

34 / Tailwind CSS v4 原子类

@tailwindcss/browser 运行时即时编译；utility 写按钮/徽章，可切暗色，class 编辑器实时预览。

35 / Jotai 原子状态

vanilla UMD 不依赖 React：多订阅共享 atom，任一处修改局部更新；一颗派生 atom 依赖两颗基础 atom。

36 / RxJS 响应式流

输入流 debounceTime(300) + switchMap 模拟搜索；鼠标移动 throttleTime 节流显示坐标。

37 / Lit Web Components

动态 import ESM 加载 Lit，注册 <live-clock> 与 <count-up>：Shadow DOM 封装、响应式属性、框架无关。

38 / 滚动驱动动画

CSS view-timeline 让动画进度直接绑定滚动位置：卡片随进入视角缩放、上浮、变色，零 JS。

39 / :has() 选择器

:has() 让父级感知子级状态：勾选卡片即整卡高亮加徽章，跨分支影响无需 JS 类切换。

40 / Container Queries

容器查询按「容器宽度」而非视口响应：拖窄容器，卡片自动从横排变纵排、字号变小。

41 / Anchor Positioning

锚点定位让弹层相对任意锚点摆放：拖拽锚点，气泡自动跟随；点击切换四向位置。

42 / View Transitions

document.startViewTransition() 让视图切换拥有平滑的交叉淡化，浏览器自动捕获新旧状态。

43 / Clipboard 剪贴板

Async Clipboard API 读写剪贴板：复制演示文本、读取剪贴板内容，均可在 file:// 下工作。

44 / Speech 语音合成

SpeechSynthesis 让页面开口朗读：中文朗读演示文案，语速可调，支持播放与停止。

45 / Web Worker

Worker 把重计算搬到后台线程：求第 40 万位的质数区间，主线程动画依然满帧流畅。

46 / Fullscreen + Wake Lock

全屏沉浸 + 屏幕常亮：适合演示、阅读、看板等场景，两个 API 都由用户手势触发。

47 / Web Share

Web Share 调起系统分享面板（移动端友好），桌面端自动降级为复制链接 + 提示。

48 / 原生对话框 + Popover

showModal() 自带焦点陷阱、Esc 关闭与 ::backdrop 遮罩；popover 属性则是轻量浮层。两者都不需要一行第三方 JS。

49 / ⌘K 命令面板

输入即过滤，↑↓ 移动高亮，Enter 执行，Esc 关闭——命令面板的全部要素，60 行原生 JS。

50 / 虚拟滚动（10 万行）

DOM 里始终只有约 8 个节点，滚动时按 scrollTop 换一批。10 万行也不掉帧。

51 / 前后对比滑块

一个 range 输入控制 clip-path 的 inset 百分比，无需 canvas，也不用两张图对齐。

52 / 拖拽上传 + 预览

dragover 高亮、drop 取文件、URL.createObjectURL 即时预览，全程不联网、不上传。

53 / Scroll Snap 吸附

两行 CSS 就得到带惯性的横向吸附，不需要轮播库，也不拦截原生滚动。

54 / @property 色阶生成

注册一个 --hue 自定义属性后，color-mix 在 oklab 空间里插值，一个输入生成整条色阶。
